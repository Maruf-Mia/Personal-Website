# Maruf Mia — Personal Portfolio

A modern, responsive portfolio inspired by the structure and visual language of the referenced research portfolio, rebuilt from scratch with Maruf Mia's software-engineering profile.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Netlify/Vercel compatible

## Run
Open `index.html` directly, or use VS Code Live Server.

## Customize
Edit `index.html` for personal information, links, projects and education.
Edit `assets/css/style.css` for design.
Edit `assets/js/script.js` for animations and typing text.

## Important
Replace placeholder email, GitHub, LinkedIn and project URLs before publishing.
Put your CV at `assets/Maruf-Mia-CV.pdf`.
